# Gilgamesh: The God-Defier

A browser-based third-person action-adventure prototype inspired by the legendary king of Uruk.

## Current build — Chapter I: The Restless King

The playable foundation now includes:

- Stylized 3D Uruk with walls, towers, city blocks, court and Great Gate
- Playable Gilgamesh with crown and sword visual
- Third-person movement and draggable camera
- Mobile touch controls
- Three-step attack combo
- Block, dodge and Royal Wrath abilities
- Guardian enemy AI, rewards and respawn recovery
- XP, levels, HP and Royal Wrath progression
- Five-branch skill tree: Might, Stone Guard, Storm Step, Defier Will and Royal Command
- Collectible relics
- Quest progression from the Great Gate to the Royal Court
- Messenger NPC and Chapter I dialogue sequence
- Citizens placed around the court
- Save/load through browser local storage
- Responsive title, HUD, pause, skill-tree and dialogue interfaces

## Run

This is a static web game. Open `index.html` from a static web host or use a local development server. Three.js is loaded from a CDN.

### GitHub Pages

1. Open repository **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

## Roadmap

The project is being built incrementally so each milestone can be checked before the next one:

1. **Foundation** — playable Uruk, movement, camera, HUD and core combat ✅
2. **Living Uruk** — NPCs, Messenger, dialogue, court interactions and improved combat feel ✅
3. **Champions** — stronger enemy variants, boss encounter, quest markers and reward loops
4. **Royal Arsenal** — weapon/relic presentation, equipment screen and expanded five-branch skills
5. **The Journey** — chapters II–VII, new regions, side quests and story encounters
6. **Mythic Systems** — achievements, Trial of Champions, audio hooks and richer world events
7. **Polish** — performance, mobile UX, accessibility, visual pass and final campaign flow

The goal is a lightweight browser experience that can grow without turning the repository into one giant unmaintainable file.
