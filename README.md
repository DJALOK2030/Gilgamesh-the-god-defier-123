# Gilgamesh: The God-Defier

A browser-based third-person action-adventure prototype inspired by the legendary king of Uruk.

## Chapter I — The Restless King

The first playable build includes:

- Stylized 3D Uruk environment with walls, towers, city blocks and the Great Gate
- Playable Gilgamesh character with crown and sword visual
- Third-person camera and keyboard movement
- Mobile touch controls
- Attack, block, dodge and Royal Wrath combat abilities
- Guardian enemy AI and defeat rewards
- XP, levels, HP and Royal Wrath progression
- Five-branch skill tree: Might, Stone Guard, Storm Step, Defier Will and Royal Command
- Collectible relics
- Main quest progression through Chapter I
- Save/load using browser local storage
- Responsive HUD and title/pause menus

## Run

This is a static web game. Open `index.html` from a static web host or use a local development server. Three.js is loaded from a CDN.

For GitHub Pages: Repository Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save. GitHub will provide the published Pages URL after deployment.

## Development direction

The prototype is intentionally incremental. Future milestones can add richer character models, animation, dialogue/NPC systems, bosses, side quests, chapters II–VII, relic sets, achievements, audio, better camera/combat feel, and a larger world while keeping the browser build lightweight.
